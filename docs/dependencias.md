# Dependências (Baseline)

Projeto Flutter utilizando as seguintes bibliotecas chave (`pubspec.yaml`):

1. **`supabase_flutter: ^2.4.0`**
   - Core para conexão com banco de dados, auth (futuro) e APIs do Supabase.
2. **`http: ^1.6.0`**
   - Ferramenta genérica para chamadas HTTP externas (ainda não muito utilizada, provavelmente preparatória para APIs).
3. **`url_launcher: ^6.3.2`**
   - Suporte a abertura de URLs, e-mails, telefone, ou o próprio app do WhatsApp (indicativo de estratégia anterior de clique simples "abrir zap").
4. **`cupertino_icons: ^1.0.8`**
   - Ícones estilo Apple.

O projeto demanda Dart 3.11+.
